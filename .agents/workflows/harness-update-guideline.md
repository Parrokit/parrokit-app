# 하네스 업데이트 가이드

## 업데이트 트리거

1. 같은 실수/리뷰 코멘트가 2회 이상 반복
2. 프로젝트 구조 또는 스택이 실제 변경
3. 팀 합의 규칙이 새로 생김

## 업데이트 원칙

1. 최소 변경: 필요한 문장만 수정
2. 강제 규칙 우선: 모호한 권장 표현 지양
3. 중복 금지: 같은 규칙은 한 곳에만 유지
4. 토큰 절약: 긴 예시보다 체크리스트 우선

## 변경 절차

1. 변경 목적 1줄 작성
2. 수정 파일 최소화 (`AGENTS.md` 우선, 필요 시 워크플로)
3. 영향 범위 확인 후 커밋
4. 커밋/PR 본문에 변경 이유 1줄 기록
