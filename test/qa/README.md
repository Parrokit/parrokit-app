# QA 실행 가이드

이 폴더는 "매번 동일한 기준"으로 점검하기 위한 QA 템플릿이다.

## 1) Quick QA (개발 중)

1. `flutter analyze`
2. 수정한 화면 직접 진입
3. 핵심 동작 1회 수행(등록/수정/삭제 중 해당되는 것)

## 2) PR QA (머지 전)

1. `flutter analyze`
2. 영향 범위 테스트 실행
3. `qa_checklist.md` 체크 완료

## 3) Release QA (배포 전)

1. 핵심 회귀 시나리오 전체 점검
2. 크래시/무한로딩/데이터 손실 여부 확인
3. 릴리즈 노트 반영 확인

## 규칙

- 테스트는 "새로 고민"보다 "템플릿 재사용"을 우선한다.
- 버그가 재발한 기능은 `smoke/community_smoke_test.dart`에 케이스를 추가한다.
