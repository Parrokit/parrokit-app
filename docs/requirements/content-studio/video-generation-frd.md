# 프롬프트 기반 Video 생성 기능 FRD (초안)

## 1. 목적
사용자가 프롬프트로 학습용 영상을 생성하고, 생성 결과를 독립적으로 저장/활용할 수 있게 한다.

## 2. 문제 정의
- 사용자 직접 촬영/업로드 의존으로 학습 콘텐츠 확보 속도가 느리다.
- 특정 주제/상황 대화 콘텐츠를 빠르게 만들기 어렵다.

## 3. 범위 (MVP)
### In Scope
- 프롬프트 기반 영상 생성 요청
- 짧은 길이 영상 생성(최대 10초, 사용자 선택)
- 대사 입력 필드와 상황 프롬프트 입력 필드 분리
- 프레임/화면 비율 사용자 선택
- 생성 영상 로컬 자동 저장 및 재사용
- 자동자막 화면에서 `콘텐츠 제작` 버튼으로 생성 스튜디오 리다이렉트
- 생성 완료 시 로컬 동영상 주소를 자동자막 화면으로 전달하여 즉시 점프
- 자동자막 화면에서 진입한 경우, 생성 스튜디오 종료 시에도 로컬 동영상 주소를 유지한 채 원래 자동자막 화면으로 복귀
- 구현 경로: `feature/content-studio/video`
- 라우트: `/content-studio/video` (스튜디오 진입 허브는 `/content-studio/hub`)
- 자동자막 라우트 권장: `/content-studio/captioning` (기존 clip-editor 하위 구현은 내부 모듈로 유지 가능)

### Out of Scope
- 고급 영상 편집 타임라인
- 장면 단위 정밀 제어(카메라 경로, 프레임 단위 편집)
- 모델별 고급 파라미터 전면 노출

## 4. 핵심 사용자 플로우
0. 자동자막 화면에서 사용자가 `콘텐츠 제작` 버튼 선택
1. 사용자가 대사 입력(예: 외칠 대사)
2. 사용자가 상황 프롬프트 입력(영상 맥락)
3. 프레임/화면 비율 선택
4. 영상 길이(초) 제한 범위 내에서 선택
5. 영상 생성 요청
6. 생성 완료 영상을 로컬 자동 저장
7. 로컬 동영상 주소를 포함해 자동자막 화면으로 점프 또는 복귀
8. 저장된 결과를 이후 자동자막/쉐도잉 또는 컬렉션에서 활용

## 5. 기능 요구사항 (FR)
- FR-VID-01: 자동자막 시작 화면에서 `프롬프트로 영상 생성` 진입 가능
- FR-VID-02: 입력 필드는 `대사 입력`과 `상황 프롬프트`를 분리한다.
- FR-VID-03: 영상 길이는 짧은 길이 정책(초 제한)을 적용한다.
- FR-VID-04: 사용자는 프레임/화면 비율을 선택할 수 있다.
- FR-VID-05: 생성 실패/지연 시 상태 표시 및 재시도 제공
- FR-VID-06: 생성 성공 시 영상을 사용자 로컬에 자동 저장한다.
- FR-VID-07: 저장된 영상은 기존 컬렉션 자동재생에서 동일하게 재생 가능하다.
- FR-VID-08: Video 생성 기능은 TTS 생성 기능과 독립적으로 동작한다.
- FR-VID-09: Video 생성 비용은 앱 화폐 `패롯` 단위로 차감한다.
- FR-VID-10: 자동자막 화면에는 생성 스튜디오로 이동하는 `콘텐츠 제작` 버튼을 제공한다.
- FR-VID-11: 생성 성공 시 앱은 로컬 동영상 주소를 payload로 자동자막 화면으로 전달해 즉시 이동한다.
- FR-VID-12: 자동자막 화면에서 스튜디오로 진입한 세션은 복귀 시에도 동일 로컬 동영상 주소 컨텍스트를 유지한다.

## 6. 비기능 요구사항 (NFR)
- NFR-VID-01: 장시간 생성 작업의 큐 상태(대기/생성중/완료/실패) 표시 필요
- NFR-VID-02: 실패 원인(네트워크/모델실패/정책차단) 구분 표시
- NFR-VID-03: 생성 실패 처리와 재시도 정책은 서비스 정책에 따라 자동 제어한다.
- NFR-VID-04: 생성 결과 포맷과 해상도의 최소 기준 정의 필요

## 7. 수용 기준 (AC)
- AC-VID-01: 사용자가 `대사 입력`과 `상황 프롬프트`를 분리해 입력할 수 있다.
- AC-VID-02: 사용자가 영상 프레임/화면 비율을 선택할 수 있다.
- AC-VID-03: 영상 길이 제한 범위 내에서만 생성 요청이 가능하다.
- AC-VID-04: 생성 성공 영상이 사용자 로컬에 자동 저장된다.
- AC-VID-05: 저장된 영상이 컬렉션 자동재생 대상에 포함된다.
- AC-VID-06: 생성 시 패롯 차감 내역이 반영된다.
- AC-VID-07: 자동자막 화면에서 `콘텐츠 제작` 버튼으로 생성 스튜디오 진입이 가능하다.
- AC-VID-08: 생성 완료 후 로컬 동영상 주소가 자동자막 화면으로 전달되어 즉시 진입한다.
- AC-VID-09: 자동자막 화면에서 진입한 경우 생성 후 복귀 시에도 동일 로컬 동영상 주소가 유지된다.

## 8. 오픈 이슈
- 영상 길이는 최대 10초로 확정(1초 단위 선택 여부는 추후 확정)
- 프레임 옵션은 사용자 선택 방식으로 확정(초기 노출 목록은 추후 확정)
- 대사 입력/상황 프롬프트 최대 글자 수는 러프 정책으로 시작하고, 운영 데이터 기반으로 추후 확정
- 1차 지원 모델/벤더 선정(품질/속도/비용 기준) 필요
