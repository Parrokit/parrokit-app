# Shadowing 거울 촬영 모드 기능 FRD (초안)

## 1. 목적
사용자가 거울을 보듯 자신의 표정/입모양/발화를 확인하면서 쉐도잉을 수행할 수 있도록, 카메라 촬영 기반 연습 모드를 제공한다.

## 2. 문제 정의
- 기존 쉐도잉은 음성/자막 중심으로 진행되어 발화 자세, 표정, 입모양 피드백이 제한적이다.
- 사용자가 자기 발화를 시각적으로 점검할 수 있는 연습 경험이 필요하다.

## 3. 범위 (MVP)
### In Scope
- 전면 카메라 기반 쉐도잉 연습 모드
- 실시간 미리보기(거울형 뷰)
- 연습 중 녹화 시작/정지
- 자막/스크립트 오버레이 표시
- 연습 결과 로컬 저장
- 재생 및 삭제

### Out of Scope
- 자동 발음 점수화
- 얼굴 인식 기반 피드백
- 라이브 스트리밍
- SNS 자동 공유

## 4. 핵심 사용자 플로우
1. 사용자가 쉐도잉 거울 모드 진입
2. 전면 카메라 권한 확인 후 거울형 미리보기 표시
3. 자막/스크립트를 보며 녹화 시작
4. 연습 완료 후 녹화 종료
5. 결과 영상 확인 후 저장/삭제 선택

## 5. 기능 요구사항 (FR)
- FR-SMR-01: 사용자는 쉐도잉 전용 거울 촬영 모드에 진입할 수 있어야 한다.
- FR-SMR-02: 모드는 전면 카메라 실시간 미리보기를 제공해야 한다.
- FR-SMR-03: 사용자는 연습 중 녹화를 시작/정지할 수 있어야 한다.
- FR-SMR-04: 연습 중 자막 또는 스크립트 오버레이를 표시할 수 있어야 한다.
- FR-SMR-05: 녹화 결과는 사용자 로컬 저장소에 저장되어야 한다.
- FR-SMR-06: 사용자는 촬영 직후 결과 재생/삭제를 수행할 수 있어야 한다.
- FR-SMR-07: 모드는 기존 쉐도잉/문장 모음집 플로우와 독립적으로 동작 가능해야 한다.
- FR-SMR-08: 사용자는 필요 시 결과를 컬렉션에 추가하는 후속 액션을 선택할 수 있어야 한다.

## 6. 데이터 계약(초안)
### ShadowingRecording
- recordingId: string
- ownerUserId: string
- localVideoUri: string
- relatedSentenceId: string?
- relatedCollectionId: string?
- durationSec: number
- createdAt: timestamp
- updatedAt: timestamp

### MirrorModeSetting
- ownerUserId: string
- showScriptOverlay: bool
- overlayPosition: string?
- cameraFacing: enum(`front`)
- updatedAt: timestamp

## 7. 권한/디바이스 요구사항
- 최초 진입 시 카메라/마이크 권한 요청이 필요하다.
- 권한 거부 시 재요청 또는 설정 화면 이동 경로를 제공해야 한다.
- 디바이스 저장공간 부족 시 녹화를 시작하지 않고 안내해야 한다.

## 8. 예외/에러 규칙
- 녹화 중 앱 백그라운드 전환 시 안전하게 녹화를 중지하고 상태를 복구해야 한다.
- 카메라 초기화 실패 시 재시도 UI를 제공해야 한다.
- 파일 저장 실패 시 임시 파일 정리 및 오류 안내를 표시해야 한다.

## 9. 비기능 요구사항 (NFR)
- NFR-SMR-01: 미리보기 지연은 사용자 체감상 자연스러운 수준을 유지해야 한다.
- NFR-SMR-02: 녹화 중 앱 안정성(크래시/프리징) 방지를 최우선으로 해야 한다.
- NFR-SMR-03: 저장 파일 용량/길이에 대한 기본 가이드 또는 제한 정책을 제공해야 한다.
- NFR-SMR-04: 민감 권한(카메라/마이크) 사용 목적을 명확히 고지해야 한다.

## 10. 수용 기준 (AC)
- AC-SMR-01: 사용자는 전면 카메라 거울형 미리보기를 보며 연습할 수 있다.
- AC-SMR-02: 녹화 시작/정지 후 결과 영상이 로컬에 저장된다.
- AC-SMR-03: 자막/스크립트 오버레이를 보며 연습할 수 있다.
- AC-SMR-04: 촬영 직후 결과를 재생하고 삭제할 수 있다.
- AC-SMR-05: 권한 거부/저장 실패 등 예외 상황에서 사용자 안내가 제공된다.
