# 언어별 회화 유튜버 추천 기능 FRD (초안)

## 1. 목적
사용자가 학습하려는 언어에 맞는 회화 중심 유튜버를 빠르게 찾고, 학습 콘텐츠 탐색 시간을 줄인다.

## 2. 문제 정의
- 초보 사용자는 어떤 유튜브 채널이 회화 학습에 적합한지 판단하기 어렵다.
- 앱 내에서 언어별 추천 진입점이 없어 외부 검색으로 이탈이 발생한다.

## 3. 범위 (MVP)
### In Scope
- 언어 선택/검색어 기반 추천 목록 조회
- 추천 채널 카드(채널명, 설명, 언어 태그, 링크)
- 채널/영상 외부 링크 이동(YouTube 앱/웹)
- 기본 정렬(인기도/최신성 중 1개 이상)

### Out of Scope
- 개인화 추천 모델
- 자동 자막 품질 분석 기반 추천
- 영상 내 문장 자동 추출
- 제휴/광고 노출 최적화

## 4. 핵심 사용자 플로우
1. 사용자가 추천 페이지 진입
2. 학습 언어 선택 또는 검색어 입력
3. 언어/검색어 기반 유튜버 목록 확인
4. 채널 또는 대표 영상 링크로 이동

## 5. 기능 요구사항 (FR)
- FR-YT-01: 사용자는 학습 언어를 선택해 해당 언어 추천 채널 목록을 조회할 수 있어야 한다.
- FR-YT-02: 사용자는 검색어를 입력해 추천 목록을 필터링할 수 있어야 한다.
- FR-YT-03: 추천 항목은 최소 `channelId`, `channelName`, `languageCode`, `summary`, `youtubeUrl`을 제공해야 한다.
- FR-YT-04: 추천 목록은 빈 결과일 때 대체 안내(검색어 수정/인기 채널 보기)를 제공해야 한다.
- FR-YT-05: 추천 클릭 시 YouTube 외부 링크로 이동할 수 있어야 한다.
- FR-YT-06: 사용자는 관심 채널을 즐겨찾기(북마크)할 수 있어야 한다.
- FR-YT-07: 추천 데이터 소스는 운영자가 갱신 가능한 구조여야 한다(정적 목록/백엔드 목록 중 택1).

## 6. 데이터 계약(초안)
### RecommendedYoutuber
- channelId: string
- channelName: string
- languageCode: string
- tags: string[]?
- summary: string
- youtubeUrl: string
- thumbnailUrl: string?
- score: number?
- updatedAt: timestamp

### UserYoutuberBookmark
- bookmarkId: string
- userId: string
- channelId: string
- createdAt: timestamp

## 7. 예외/에러 규칙
- 네트워크 실패 시 재시도 버튼을 제공해야 한다.
- 외부 링크가 유효하지 않으면 오류 메시지와 대체 채널을 제시해야 한다.
- 검색어 결과가 0건이면 추천 검색어 예시를 제공해야 한다.

## 8. 비기능 요구사항 (NFR)
- NFR-YT-01: 추천 목록 최초 로딩은 사용자 체감상 빠르게 표시되어야 한다.
- NFR-YT-02: 언어/검색어 변경 시 목록 재조회는 지연 없이 반영되어야 한다.
- NFR-YT-03: 추천 데이터 갱신 이력(업데이트 시각)을 유지해야 한다.
- NFR-YT-04: 외부 링크 이동 전후 앱 복귀 동선이 보장되어야 한다.

## 9. 수용 기준 (AC)
- AC-YT-01: 언어 선택 시 해당 언어 추천 채널 목록이 표시된다.
- AC-YT-02: 검색어 입력 시 목록이 필터링된다.
- AC-YT-03: 추천 항목 클릭 시 YouTube 채널/영상으로 이동한다.
- AC-YT-04: 즐겨찾기한 채널을 다시 확인할 수 있다.
- AC-YT-05: 결과 없음/네트워크 오류 상황에서 대체 안내가 제공된다.

## 10. 오픈 이슈
- 추천 데이터 소스를 정적 번들로 둘지, Firebase 컬렉션으로 관리할지 확정 필요
- 정렬 기준(인기도/최신성/운영 추천) 우선순위 확정 필요
- 언어 코드 표준(ISO 639-1 등) 확정 필요
- 저작권/브랜드 사용 가이드(썸네일/채널명 노출) 검토 필요
