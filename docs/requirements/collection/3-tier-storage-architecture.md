# 3-Tier 저장소 아키텍처 및 비즈니스 모델 요구사항

## 1. 목적
앱의 저장 방식과 비즈니스 모델을 3가지 티어(무료 로컬, 개인 클라우드 백업, 전용 서버 동기화)로 분리하여 사용자의 선택권을 보장하고 서버 비용을 최적화하는 구조적 기반을 마련한다.

## 2. 3-Tier 아키텍처 정의 (Repository Pattern)

UI 코드와 DB 코드를 완전히 분리하는 **저장소 추상화(Repository Pattern)**를 도입하여, 사용자의 멤버십 등급에 따라 내부 데이터 소스를 유연하게 교체할 수 있도록 설계한다.

### 2.1. Tier 1: 로컬 전용 모드 (Free Tier)
- **대상**: 기본 무료 사용자
- **저장 매체**: 기기 내 로컬 DB(Drift SQLite) 및 내부 스토리지(`path_provider`)
- **특징**:
  - 오프라인에서 매우 빠르고 가볍게 동작한다.
  - 앱 삭제 시 또는 기기 변경 시 데이터가 유실된다.
  - 서버 유지비용이 전혀 발생하지 않는다.

### 2.2. Tier 2: 개인 클라우드 백업 모드 (Premium Tier A)
- **대상**: 단건 결제 또는 저가형 구독 사용자
- **저장 매체**: 기기 내 로컬 DB + 사용자의 개인 클라우드(Apple iCloud, Google Drive)
- **특징**:
  - 평소에는 로컬(Tier 1)과 동일하게 작동하여 속도가 빠르다.
  - 사용자가 원할 때(수동) 또는 특정 시점(앱 종료 시 등)에 로컬 DB 파일과 미디어 폴더를 압축하여 개인 클라우드 공간에 업로드/백업한다.
  - 기기 변경 시 클라우드에서 백업본을 내려받아 복구할 수 있다.
  - **개발자 측면의 이점**: 미디어 파일 등 대용량 트래픽 및 스토리지 비용을 사용자의 개인 클라우드에 전가하므로 서버 비용이 0원이다.

### 2.3. Tier 3: 전용 서버 동기화 모드 (Premium Tier B)
- **대상**: 정기 구독(프리미엄) 사용자
- **저장 매체**: Firebase (Firestore + Storage)
- **특징**:
  - 로컬 DB를 거치지 않으며, Firebase가 데이터의 Source of Truth가 된다.
  - 다중 기기 환경에서 매끄러운 실시간 동기화를 지원한다.
  - (참고) Firestore의 오프라인 캐싱 기능을 통해 네트워크가 끊겨도 조회가 가능하다.
  - 향후 '콜렉션 공유', '커뮤니티 기능' 등 서버 기반 확장 기능의 뼈대가 된다.

## 3. 설계 요구사항 (FR)
- **FR-3TIER-01**: `MediaRepository` 인터페이스를 정의하고, 기능별 구현체(`LocalMediaRepository`, `CloudMediaRepository`)를 캡슐화해야 한다.
- **FR-3TIER-02**: 티어 2(개인 클라우드) 작동을 위한 `CloudBackupService`를 별도로 분리하여, iCloud 및 Google Drive API와 통신하는 인터페이스를 구현해야 한다.
- **FR-3TIER-03**: 앱 실행 시 현재 사용자의 구독 상태(Tier)를 판별하여 적절한 Repository를 UI에 주입(Inject)해야 한다.
- **FR-3TIER-04**: 사용자가 티어 업그레이드(Tier 1 -> Tier 3)를 진행할 경우, 로컬 데이터를 Firebase로 이관(Migration)하는 유틸리티가 제공되어야 한다.
- **FR-3TIER-05**: 로컬-클라우드 간 미디어 파일 '스왑(Swap)' 로직 시 DB 레코드의 이동이 아닌, 미디어 파일의 다운로드/캐시 상태만 변경하는 방식으로 구현해야 한다.

## 4. 수용 기준 (AC)
- **AC-3TIER-01**: 티어 1(무료) 상태에서는 Firebase 통신이 전혀 발생하지 않는다.
- **AC-3TIER-02**: 티어 2 상태에서는 사용자의 Google Drive 또는 iCloud 계정 권한을 요청하고 백업 파일을 업로드/다운로드 할 수 있다.
- **AC-3TIER-03**: 티어 3 상태에서는 콜렉션 추가 시 즉각적으로 Firestore에 데이터가 반영되며 타 기기에서 실시간으로 확인할 수 있다.
